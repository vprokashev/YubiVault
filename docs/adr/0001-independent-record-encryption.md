# Независимое шифрование записей

Каждая запись и её сохранённые версии хранятся в самостоятельных файлах OpenPGP с непрозрачными идентификаторами. Это позволяет открывать один секрет и сохранять его изменения без расшифровки и перезаписи остальных секретов: существующий общий файл делает обе операции неудобными и повышает цену ошибки при сохранении. Каталог имён шифруется отдельно; безопасное согласование изменений записи и каталога должно учитывать прерывание сохранения.
