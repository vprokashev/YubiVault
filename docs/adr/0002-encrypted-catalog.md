# Зашифрованный каталог и непрозрачные имена файлов

Имена записей хранятся в отдельном зашифрованном каталоге, а пути файлов содержат непрозрачные идентификаторы. Это скрывает названия записей при просмотре заблокированного хранилища, ценой отдельной расшифровки каталога и необходимости согласовывать его обновление с файлами записей. Пользователь выбрал эту схему вместо имён записей в открытых именах файлов.

Каталог является отдельным файлом `index.gpg`, содержащим имена, ссылки на текущие и исторические версии, даты и контрольные данные. При разблокировке он расшифровывается только в память; это позволяет показать список имён без расшифровки содержимого всех записей. При выборе имени отдельно расшифровывается нужная версия записи, а при сбросе сеанса расшифрованный каталог удаляется из состояния приложения.
